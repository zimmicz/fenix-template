# Fenix heating robot (template)

Your private copy of this repository runs an hourly job for the Fenix V24 heating web app (https://www.zimmi.cz/fenix/): it logs your rooms, checks the weather forecast, sends notifications and, if you turn it on, switches sunny rooms to eco.

Setup guide: open the app and tap **Setup guide** (no login needed), or see https://github.com/zimmicz/fenix#setup.

Keep this copy **private**: `data/log.csv` shows when you are at home.
